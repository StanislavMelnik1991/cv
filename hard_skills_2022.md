## Хард скилы, подтверждённые практикой

### 1. Backend на Node.js и TypeScript
**Уровень:** базовый / уверенный  
**Проекты:** pixelplex_nodejs_course, URA-Remont, nyblecraft-test

- Разработка HTTP API на Node.js, TypeScript и Express: маршрутизация, контроллеры, DTO и обработка параметров запросов.
- Проектирование серверной архитектуры: разделение router/controller/service, модули пользователя и игры, enum-ы и бизнес-правила.
- Валидация входных данных через `express-validator`, централизованная обработка ошибок и HTTP-статусов.
- Разработка авторизации и ролей: JWT, bcrypt, проверка прав доступа (в том числе роль администратора).
- Миграция и запуск серверного проекта на NestJS; базовая работа с модулями NestJS.

### 2. Реляционные и NoSQL базы данных
**Уровень:** базовый / уверенный  
**Проекты:** pixelplex_nodejs_course, URA-Remont

- Моделирование связей, внешних ключей и каскадного удаления.
- Базовое проектирование структуры MongoDB.
- Docker Compose для запуска зависимостей разработки.
