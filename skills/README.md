# Навыки и основания для резюме

- [hard_skills.md](hard_skills.md) — актуальная объединённая сводка навыков.
- [confirmations.md](confirmations.md) — уточнения кандидата и границы допустимых формулировок, включая агентную разработку и серверные задачи.
- Годовые анализы: [2022](hard_skills_2022.md), [2023](hard_skills_2023.md), [2024](hard_skills_2024.md), [2025](hard_skills_2025.md), [2026](hard_skills_2026.md).
- [hard_skills_selfprojects.md](hard_skills_selfprojects.md) — анализ личных проектов.

Годовые анализы сохраняют исходный период исследования. Упоминание библиотеки в конфигурации не означает самостоятельный опыт; числа коммитов не используются как метрика производительности. Новые уточнения добавляются с датой и источником, без пересчёта старого исследования задним числом.

Полные резюме находятся в [resumes/frontend](../resumes/frontend/) и [resumes/ai-first](../resumes/ai-first/); сокращённые PDF-тексты — в [resume/content](../resume/content/). При редактуре согласовывайте факты и языковые версии. Приватные переписки, исходники работодателей и браузерные сессии хранятся вне отслеживаемых файлов.
